# `renderer/` — HTML 렌더러 계약 (§7.1) · 게이트 **G2**

## 이 계약이 고정하는 것

**렌더러가 둘째 판정 층이 되지 않는다**는 것을 기계로 확인한다(§12의 명시 위험).

- **JSON의 순수 함수**(D28). 렌더러는 숫자를 계산하지 않고, 점수·순위를 만들지 않고, 정렬은 JSON이 정한 키로만 한다. → HTML에서 뽑은 모든 숫자가 JSON 안에 **존재해야** 한다.
- **판정 색 금지**(D67). 좋음/나쁨을 뜻하는 빨강/초록 대신 단일 색상의 **농도**와 방향 기호(▲▼). 예외는 `gate.json`의 정책 결과뿐.
- **판정 어휘 금지** — bad / poor / 나쁨 / 위험 / 불량 …. 사전 검사로 강제한다.
- **자립형 단일 HTML** — d3 인라인, 데이터는 `<script type="application/json">`, **네트워크 요청 0건**. 슬랙에 던지고 회의실에서 열리고, 샌드박스·오프라인 CI에서도 열려야 한다.

## 최소 케이스 (§2.9)

| 케이스 | 무엇을 잡나 | 상태 |
|---|---|---|
| 숫자 존재 검사 | HTML에서 추출한 모든 수치가 JSON에 있다(순수 함수) | 미작성 |
| 판정 어휘 사전 | 금지 어휘 사전 검사 통과 | 미작성 |
| URL 해시 복원 | aspect 토글 상태가 URL 해시에서 복원된다 | 미작성 |
| 네트워크 0건 | 자립형 — 외부 요청 시도 0 | 미작성 |
| 렌더 시간 | 파일 5,000개 픽스처의 렌더 시간(성능 목표 60fps, ≤ 3MB) | 미작성 |

범례 고정 문구도 이 계약에 든다: **"크기는 코드 양이지 문제 크기가 아니다"**(§12).
