# `contract/schema/base/` — 손으로 쓴 긍정 문서

§7에 예시가 있는 여섯(report·gate·validate·campaign·event·fixture_change)은 `prd:§7:<이름>`으로 **prd.md에서 직접** 읽는다 — 예시가 곧 픽스처이므로(D26) 복사본을 두면 드리프트한다.

여기 있는 것은 §7에 예시가 없는 것뿐이다.

- **`change.json`** — §7에 change.json 예시가 없다 — §5.1은 표(질문 -> 계산)와 항목의 모양만 준다. 이 문서는 §5.1·§5.2·§5.7의 문장에서 직접 만든 **최소 긍정 문서**이고 손으로 쓴 전제다. D128로 §7 예시가 contract/lens/에서 생성되면 change도 같은 자리를 갖게 될지는 그때 결정한다.

문서에 `$comment` 같은 설명 필드를 두지 않는다. 스키마가 닫혀 있어(D126) 인스턴스에 없는 속성은 거부되고, 그것이 맞다 — 설명은 이 README의 자리다.
