# `cpd/` — CPD 집계 계약 (§2.6) · 게이트 **G0**

## 이 계약이 고정하는 것

**중복을 "쌍"이 아니라 "클러스터"로 센다**는 것과, 클러스터에서 파일·쌍 단위 숫자를 뽑는 투영 규칙을 못 박는다.

- **중복 클러스터** = 같은 정규화 토큰 열의 **모든** 발생 `{(파일, 시작, 끝 토큰)}`. ID = `dup:<정규화 토큰 해시>:<토큰 수>`. A↔B와 C↔D가 같은 열이면 CPD가 이미 **한 객체**로 낸다 — 이것이 CPD `Match`의 원래 의미다(D39).
- **파일별** `union_dup_tokens` = 그 파일의 모든 발생 구간 **합집합**(겹침 병합).
- **쌍별** `pair_dup_tokens(A,B)` = 발생 집합이 A·B를 모두 포함하는 클러스터들의 **A쪽** 구간 합집합 토큰 수(A = 경로 사전순 앞) — 무순서 쌍이 한 값을 갖게 하는 규칙.
- **자기 중복** = 발생이 한 파일에만 있는 클러스터 → `self_dup_tokens`, **twin이 아니다**.

`union_dup_tokens`가 Dx의 질량 성분이고(§3.2 "비율이 아니라 질량"), `pair_dup_tokens = 0`이 §6.3 중복 합격 함수의 판정 기준이라 이 투영이 틀리면 지도와 검증이 함께 틀린다.

## 최소 케이스 (§2.9)

| 케이스 | 무엇을 잡나 | 상태 |
|---|---|---|
| 겹침 합집합 | `[100,200) ∪ [150,250)` = **150**(250이 아니다) | 미작성 |
| 무순서 쌍 | `pair_dup_tokens(A,B) = pair_dup_tokens(B,A)`, A쪽 투영으로 고정 | 미작성 |
| 자기 중복 | 한 파일 안의 반복 → `self_dup_tokens`, `twins` 증가 없음 | 미작성 |
| 임계 경계 | `minimumTokens=100`에서 99토큰은 클러스터가 아니고 100토큰은 맞다 | 미작성 |
| 같은 열 4발생 | 클러스터 **1개**(쌍 6개가 아니다) | 미작성 |
