# S4-11 — 자기 중복의 '분할' (반례 (A) 불일치 · 게이트 G0 — `cpd/`)

- **인용**: §2.6 "분할로 읽는다: `union_dup_tokens`는 파일의 모든 중복 구간, `self_dup_tokens`는 그중 한 파일에만 있는 클러스터가 덮는 구간 — "twin 없이 혼자 복붙한 양"." · D166 "`union_dup_tokens` ⊇ 교차 파일 구간 ∪ 자기 중복 구간".
- **입력**(`run.py` 안 — 리뷰어 S4-11의 입력 그대로): 혼합 클러스터 x(A[0,150)·B[0,150))와 자기 클러스터 y(A[100,250)·A[300,450)) — y의 A[100,250)이 x의 A[0,150)과 [100,150) 50토큰 겹친다.
- **두 값**(`run.py`가 계산한다 — `contract/cpd/compute.py`): 분할로 읽으면 `union = self + 교차` = 300 + 150 = **450** · 계산기(⊇)의 `union_dup_tokens` = **400**. 겹친 50토큰은 twin이 있는데도 `self_dup_tokens`에 든다.
- **무엇이 갈리나**: "twin 없이 혼자 복붙한 양"은 겹침이 없을 때만 참이다 — 문장을 고치든 `self_dup_tokens`를 "교차 구간에 안 든 자기 중복"으로 재정의하든 결정이 필요하고, 재정의면 `cpd/` 값이 움직인다.
- **게이트**: 값이 `cpd/` 스위트(G0)의 것 → G0(D266).
