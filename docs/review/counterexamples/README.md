# `docs/review/counterexamples/` — 리포에 실행 가능한 반례 (D265)

G0 #1은 **재현 가능한 반례**를 센다(D265). 반례는 기록의 근거 칸에 적힌 두 값이 아니라 **커밋에 있는 입력과 계산**이 내는 두 값이다 — 기록·산문에 적힌 수는 리뷰어의 것이든 주 세션의 것이든 주장이다(B.4).

## 모양

```
<key>/run.py      두 읽기의 값을 계산해 마지막 줄에 JSON 한 줄을 낸다:
                  {"key": "<key>", "values": {"<읽기 A>": <값>, "<읽기 B>": <값>}}
<key>/README.md   입력·인용 문장(§번호)·읽기 둘이 무엇인지 — 사람이 읽는 쪽
```

- (A) **불일치**: 읽기 하나는 계약의 한 자리(문장·§7 예시·단언한 수)가 말하는 값, 다른 하나는 재계산이 내는 값.
- (B) **갈림**: 인용한 문장이 둘 다 허용하는 두 읽기의 값.
- 계산은 되도록 기존 계약 계산기(`contract/*/compute.py`)를 부르거나 그 함수를 쓴다 — 반례의 값과 닫는 판의 픽스처가 같은 기계에서 나오게.

## 기록의 표지

종합 대응표의 그 key 행에:
- `반례 — G0` + 이 디렉터리의 경로(`docs/review/counterexamples/<key>/`) — G0을 막는 열린 반례.
- `반례 — G1`·`G2b`·`G3` — 값이 그 게이트 스위트의 것(D266) — 그 게이트의 입장 목록으로(`--gate-lists`).
- 닫을 때: `닫힘 — D<n> · G0 케이스 `<스위트>/<케이스>`` — 반례를 박은 G0 케이스(고르지 않은 읽기가 그 케이스의 변조). 그 디렉터리가 없으면 `--count`가 열린 것으로 센다.
- 세우지 못하면 `후보 — <게이트>`(D267 — G0을 막지 않는다).

## 검사

`python3 docs/review/g0-review.py --counterexamples` — 이 디렉터리의 반례마다 `run.py`를 돌려 값이 아직 갈리는지 본다(`ci/check-all.sh`가 매번 돈다). 값이 같아졌거나 실행할 수 없으면 붉다. 닫는 판의 G0 케이스가 반례를 대신하면 그 디렉터리를 지운다.
