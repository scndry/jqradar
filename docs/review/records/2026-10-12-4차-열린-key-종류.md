# G0 교차 검토 — 4차 범위 안 열린 key의 종류 (결정 전 분류)

- 읽은 것: 4차 종합 `2026-10-12-종합-4차-입력을-바꾼-둘째-라운드.md`의 대응표(병합 + 미부착)에서 범위 안 열린 key **54**. `--count`가 세는 열린 집합과 같은 집합이다(생성기가 단언한다).
- 분류자: 주 세션(4차 종합자와 같다, `claude-opus-5-5`). **종류·경계·어긋남·고칠 자리가 분류자의 판단**이고, 수·절 집합·넷째 질문 열은 생성기가 개별 기록에서 계산한다.
- **결정하지 않는다.** 닫힘 표시도 붙이지 않는다 — 결정 판의 묶음을 정하는 재료다. 이 파일은 `--count`가 읽지 않는다(이름에 '종합'이 없고 개별 기록의 머리도 없다).
