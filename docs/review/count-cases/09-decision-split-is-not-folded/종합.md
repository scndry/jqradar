# 합성 종합 — D 번호가 붙은 분리를 쪼갬으로 접지 않는가 (D153) — 같은 표에 표지 있는 것과 없는 것을 둔다

행 1·2는 같은 개별(R1-7)을 가리키지만 **행 2에 `분리 — D900`이 있어** 접지 않는다 —
닫는 결정이 쪼갠 것이다(D153). 행 3·4는 같은 개별(R1-8)을 가리키면서 표지가 없어
**종합자의 쪼갬**이므로 한 key로 접는다. 둘을 같은 표에 두어야 D 번호가 실제로
가르는 표지인지 한 실행에서 보인다.
